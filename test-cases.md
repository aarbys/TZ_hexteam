## TC-001 Получение списка комнат
** Предусловия теста **
|Шаг | Результат выполнения шага|
|---|---|
|Получить корректные данные авторизации пользователя, например: login=... password=...| Корректные данные авторизации найдены|
|Пройти авторизацию и зафиксировать access_token|Авторизация пройдена, acces_token зафиксирован|

**Шаги теста**
|Шаг| Результат выполнения шага|
|---|---|
|Отправить GET запрос на /api/rooms с валидным access_token| Сервер вернул 200 статус код|
|Обратить внимание на тело ответа| Ответ содержит в себе список комнат в формате JSON (Пример ответа)[{"name": "room1","area": 1,"description": "room1","id": 3826,"owner_id": 711},{"name": "room2","area": 6,"description": "room2","id": 3858,"owner_id": 711}]|
|Обратить внимание на структуру ответа| Структура ответа содержит в себе предусмотренные API поля и имеет корректные типы данных, согласно ТЗ|
|Проверить корректность полученных данных| Данные комнат соответствуют данным, сохраненным на сервере|
